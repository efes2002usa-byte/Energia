# Energia

Веб-приложение для учёта, распределения и анализа потребления электроэнергии бара.

## Текущий этап

Текущий вертикальный срез включает рабочий интерфейс администратора и серверный backend на D1:

- адаптивный Dashboard;
- фактическое и расчётное потребление;
- переключение периода «неделя / месяц»;
- интерактивный график сверки;
- покрытие фактическими данными;
- структура потребления по категориям;
- список отклонений, требующих внимания.
- показания счётчика, ручное уточнение часов и перераспределение интервала;
- постоянные приборы, версии параметров, зоны, категории и календарь работы;
- почасовая сверка, аналитика, тепловая карта и сравнение периодов;
- настройки объекта, тарифы, пересчёты и аудит изменений.

## Стек

- React 19 + TypeScript;
- Vinext / Vite;
- Tailwind CSS;
- Recharts;
- Cloudflare Workers / OpenAI Sites.

## Локальный запуск

Требуется Node.js 22.13 или новее.

```bash
npm ci
npm run dev
```

Production-сборка:

```bash
npm run build
```

Проверка доменной арифметики и правил:

```bash
npm test
```

Данные хранятся в Cloudflare D1 через Drizzle ORM. Миграции находятся в каталоге `drizzle` и добавляются в архив публикации автоматически.
